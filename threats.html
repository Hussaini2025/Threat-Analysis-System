Common Cyber Threats

This page provides information about common cyber threats, their severity, and recommended preventive measures.

Threat Description Severity Prevention
Phishing Fraudulent emails or websites used to steal personal information. High Verify emails and avoid suspicious links.
Malware Malicious software that damages or compromises systems. Critical Install antivirus and update software regularly.
Ransomware Encrypts files and demands payment for recovery. Critical Maintain regular backups and avoid unknown downloads.
SQL Injection Attack that targets vulnerable database queries. High Use parameterized queries and input validation.
DDoS Attack Overloads a server with excessive traffic. Medium Use firewalls and DDoS protection services.
Brute Force Attack Attempts multiple password combinations to gain access. Medium Enable Multi-Factor Authentication and strong passwords.

Threat Categories

Email Threats

Phishing and spam attacks targeting users through email.

Malware

Viruses, worms, trojans, spyware, and ransomware.

Database Attacks

SQL Injection and unauthorized database access.

Network Attacks

DDoS attacks, packet sniffing, and network exploitation.
