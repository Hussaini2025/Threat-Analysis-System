Open Dashboard

Project Overview

This project demonstrates the basic concepts of Cyber Security and Ethical Hacking. It focuses on identifying cyber threats, analysing vulnerabilities, calculating risks and providing security recommendations for network protection.

Project Modules

Threat Analysis

Learn about common cyber threats and their impact.

Vulnerability Assessment

Perform a simulated vulnerability assessment.

Risk Calculator

Calculate the security risk level using simple values.

Security Recommendations

View best practices to improve network security.

Project Objectives

  • Identify common cyber threats.
  • Understand network vulnerabilities.
  • Perform basic risk assessment.
  • Recommend security controls.
  • Improve awareness of network security.
