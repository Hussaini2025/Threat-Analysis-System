About the Project

The Threat Analysis and Vulnerability Assessment for Network Security project was developed as part of a Cyber Security and Ethical Hacking internship. The purpose of this project is to demonstrate basic concepts of cybersecurity, including identifying cyber threats, assessing vulnerabilities, calculating security risks, and providing recommendations to improve network security.

Project Objectives

Threat Analysis

Identify common cyber threats that affect computer systems and networks.

Vulnerability Assessment

Understand security weaknesses that attackers may exploit.

Risk Assessment

Evaluate risks using likelihood and impact values.

Security Improvement

Recommend security controls and best practices to reduce cyber risks.
